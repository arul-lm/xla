* How to validate?
** For mesh of shape 1xdimx1
1. Run and generate comp_stats.csv
   #+begin_src bash
     docker exec xla bazel run --spawn_strategy=sandboxed //xla/service/gpu/model:analytical_latency_calculator -- --hlo-module-file=/xla/temp.mlir --format=hlo --all --gpu --print-collective-details --hardware-architectures=b200 --output-dir=temp_stats --mesh-shape=1,72,1 --overlap-factor=1.0 --fix-ragged-dot-flops
   #+end_src
2. Go to the otter/jax-llm-examples and run
   #+begin_src bash
     python calculate_flops.py --mesh 1x72x1 --batch 32 --sequence 131072 --n-routed-experts 288 --json deepseek_r1_dot_symbols.json
   #+end_src
3. use the flop_results generated by the above command in the below command (run from xla directory)
   #+begin_src bash
     arul@ip-10-100-12-71 ~/d/xla (clos)> python analyze_layers_by_op_name.py temp_stats/comp_stats.csv --dense-layers 3 --expert-layers 58 --output layer_operations.json --flops-results ../otter/jax-llm-examples/flops_results.csv
   #+end_src
4. Look at the summary generated by the above command
   1. Sharded flops expected and measured should match
   2. Unsharded flops and flops per token can be validated by running the below command
      #+begin_src
        arul@ip-10-100-12-71 ~/d/o/jax-llm-examples (main)> python deepseek_r1_param_est.py --batch-size 1 --seq-len 131072 --strategy prefill
      #+end_src
** For mesh of shape spxdimx1
1. Use the same steps as above, except use deepseek_r1_symbols_sp.json when running calculate_flops.py
